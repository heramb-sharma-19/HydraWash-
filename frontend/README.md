# HydraWash Frontend

Next-generation autonomous laundry management web application built with React, Vite, Tailwind CSS, Motion (Framer Motion), and Lucide Icons.

## Features
- **3D Interactive Agentic Factory**: Real-time canvas rendering laundry machines and operations.
- **5 Comprehensive Modals**:
  - **Complaint Portal**: Direct issue ticket submission with hostel and room mapping.
  - **Track ID Telemetry**: Order status lookup by 6-digit code or order ID with timeline stepper.
  - **Resident Profile**: Profile dashboard, RFID bag assignment, balance, and activity history.
  - **Book a Drop-off**: Garment reservation with instant 6-digit code generation.
  - **Resident Registration**: Student onboarding with hostel allocation and dedicated RFID laundry bag.
- **Strict Brand Design System**: Luxury Industrial palette (`#000000`, `#F4F1EA`, `#DCD2C4`, `#FF7A1A`).

## Quick Start
```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build production bundle
npm run build
```
